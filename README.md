# Aplicação Web - Capacitação Digital para Empreendedores

Este projeto faz parte do programa de extensão **Trilhas Formativas para Aprendizagem Online**, promovido no bairro Jardim Centenário (Campo Grande/MS), com foco na inclusão digital de pequenos empreendedores locais.

## 🧾 Descrição

A aplicação web foi desenvolvida para permitir que pequenos comerciantes criem suas próprias páginas de divulgação, com informações sobre produtos e formas de contato.

O objetivo é fornecer uma ferramenta simples, responsiva e de fácil manutenção, usando tecnologias modernas da web.

## 🚀 Tecnologias Utilizadas

- **React.js** – Framework JavaScript moderno para construção de interfaces dinâmicas;
- **HTML5** – Estruturação semântica das páginas;
- **CSS3** – Estilização responsiva e adaptada para dispositivos móveis;
- **JavaScript** – Funcionalidades e interação com o usuário.

## 📱 Funcionalidades

- Página personalizada para apresentação de produtos/serviços;
- Botão de contato via WhatsApp;
- Layout responsivo (adaptável a celular, tablet e desktop);
- Estrutura modular com componentes reutilizáveis.

## 📦 Como Executar o Projeto

### Pré-requisitos

- Node.js instalado (https://nodejs.org)
- Git instalado (https://git-scm.com)

### Instalação

```bash
# Clone o repositório
git clone https://github.com/hildomarco/capacita-o-digital-jardim-centen-rio.git

# Acesse a pasta do projeto
cd capacita-o-digital-jardim-centen-rio

# Instale as dependências
npm install

# Inicie o servidor de desenvolvimento
npm start
